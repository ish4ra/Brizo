## The logo reference

- The owner supplied a raster reference of a minimalist three-shape blue
  sailboat and selected it as the approved direction.
- Where that image came from (owner-made, AI-generated, stock, commissioned or
  third-party) has **not** been confirmed, and neither has any licence attached to it.
- The vector candidate was constructed by hand as bezier paths that follow the
  reference closely (measured shape overlap ≈ 96–98 %) and recoloured to the
  approved palette.

**Recreating an image as SVG, recolouring it, or drawing something similar does
not by itself remove any copyright or trademark issue.** If the reference is
someone else's protected work, the candidate may be too.

## What we are doing about it

1. The reference image, the vector master and all logo-derived exports are
   **kept out of this public repository**. They live in the git-ignored
   `branding-private/` folder and in a private review page shared only with
   the owner.
2. `scripts/brand/build-brand-assets.mjs` refuses to write logo-derived files
   into tracked paths.
3. The README and other public visuals use only original, source-independent artwork.
4. The design is labelled a **provisional branding candidate** everywhere.

## Needed to resolve (owner)

- [ ] Confirm the origin of the reference image and, if third-party, obtain
      written permission or a licence that allows modification and use as a
      trademark. If the origin cannot be established, commission or create an
      original mark *in the same direction* with documented authorship.
- [ ] If AI-generated: record the tool and its terms. Copyright protection for
      AI output may be limited, which affects how exclusively it can be owned.
- [ ] Run a trademark search for "Brizo" in software/browser classes
      (e.g. Nice class 9 and 42) in target jurisdictions (USPTO, EUIPO, WIPO
      Global Brand Database, and the owner's home country). Similar marks
      already exist in unrelated fields, so a search is needed before
      committing to the name.
- [ ] Decide whether and where to register the mark (paid; requires owner approval).

Once resolved, record the outcome in [DECISIONS.md](DECISIONS.md), then (with
owner approval) logo assets may be committed and used in the README.
